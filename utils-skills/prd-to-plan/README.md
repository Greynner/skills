# prd-to-plan

Turns PRDs into phased implementation plans.

## Use when

- A PRD is ready but the engineering approach is not
- You need a step-by-step plan before coding
- You want risks and unknowns surfaced early

## Install

```bash
npx skills add https://github.com/Greynner/skills.git --skill utils-skills/prd-to-plan
```
