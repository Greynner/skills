# handle-coderabbit

Triage and resolve CodeRabbit PR review comments.

## Use when

- CodeRabbit left review comments on a PR
- You want to separate useful feedback from false positives
- You need concise responses for review threads

## Install

```bash
npx skills add https://github.com/Greynner/skills.git --skill utils-skills/handle-coderabbit
```
